# 贵族动作修订

使用内置 image_gen 补画连续动作，原始参考图保留。正式透明帧保存在 `assets/chars/noble/v2/`，配置来自该目录的 `manifest.json`。独立预览：`tools/animation-review.html`。

补画提示词组（生产规格）：

- 保持金发、藏青羽帽、白领巾、蓝金披风、黑色短裤和白袜；所有动作朝右，人物比例一致，完整身体与细剑留在独立单元格内，真实透明背景，不含文字、编号、网格、阴影或相邻人物。
- 行走：接触、下沉、经过、抬升、对侧接触、对侧下沉、对侧经过、对侧抬升；腿部交替，膝盖和手臂有真实关节变化，披风延迟跟随。
- 横斩、上挑：防备、转体或屈膝蓄力、挥剑、伸展、随动、收剑、恢复防备；禁止仅平移或旋转同一张图。
- 直刺、剑气突刺：防备、收肘屈膝、踏步、伸肘出剑、完全伸展、保持弓步、收臂、恢复防备。
- 跳跃：站立、下蹲、蹬地、收腿上升、最高点、伸腿下落、缓冲、站立。防御：站立、屈膝、半跪竖剑、稳定防备。受击：防备、胸口后仰、重心后移并甩动披风、恢复。
- 低身刺：站立、深蹲、半跪收剑、低位滑步伸剑、完整低位刺击、蹲姿收剑、起身、恢复。
- 空中下劈：空中收腿、举剑、上方蓄力、向右下挥剑、向下伸展、随动、收剑、空中防备。

逐帧导出脚本：`tools/build-noble-v2.mjs`。按人工检查后的单元格提取，保留 PNG 原有 alpha；原 JPEG 倒地/起身片段单独裁切，去除标题与指示箭头。待机使用已有透明原图，避免深色服装在再次抠图时损坏。

动画按前摇、有效命中、收招分段推进；连续必杀有效段重复出剑，起身使用倒地计时末段。已有帧动画不再叠加整图走路摇摆或倒地旋转。
