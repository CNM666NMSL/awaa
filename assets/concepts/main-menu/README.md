# 标题与主界面候选方案

使用内置imagegen，以用户选定的工业雨街、现有剑客和贵族立绘为参考生成三个16:9主菜单方案。仅保存候选图，未改变游戏主菜单与名称。

共同提示：成熟像素风2D格斗游戏，黄昏工业废街、雨水、垃圾与积水反光；精确保留剑客斗笠蓑衣深色袍服和贵族羽饰礼帽蓝披风细剑形象。标题为百兽夜行；六个菜单项为剧情模式、双人对决、练习场、角色图鉴、设置、退出游戏。无战斗HUD、浏览器外框或水印。菜单留足间距，标题层级明确。

A 暮雨残街：左上银白书法金属标题，暗金副标题；左侧文字菜单、选中项琥珀色细光条；右侧双角色与橙蓝雨街，电影感。
B 夜雨孤锋：左侧剑客近景，右侧墨色半透明菜单区域；书法大标题与朱红副标题，银色剑形选中线；远处贵族小剪影，江湖氛围。
C 残街对决：顶部居中银色大标题与琥珀副标题；剑客和贵族左右相向，中间六条暗色菜单，橙色选中强调，经典格斗对峙构图。
