# 四套远攻动作和特效

| 角色／形态 | 远攻 | 主要表现 |
| --- | --- | --- |
| 江湖剑客 | 居合寒霜剑气 | 按鞘、拔刀、肩侧蓄力，横斩后收刀；银白剑气、霜雾和细碎刀光 |
| 银铠守望者·脱甲 | 绿色奥术魔法射线 | 掌心聚能、横剑媒介、竖剑导流；三枚浮游法球、绿色电光、魔法阵 |
| 银铠守望者·铠甲 | 聚能魔法冲击波 | 扶剑、提剑、竖剑聚核、剑尖前沉；贴地绿色能量波、电弧、碎石和地面裂纹 |
| 贵族决斗者 | 金色贯穿光剑 | 剑尖光点、挽剑、完整圆形剑阵、稳定突刺；金色光剑和花瓣状粒子 |

四套动作各安装 12 帧蓄力和 12 帧释放，共 96 个运行时帧文件。蓄力按三段各 4 帧前进，达到段末后保持；不会循环重播。衣摆、蓑衣、长发、披风和武器的姿势均包含在新绘制的帧图中。

三段阈值为 0 秒、1 秒、2.5 秒；7 秒自动释放最高段，继续按住不能重复起手。伤害倍率为基础伤害的 1 / 1.4 / 1.8，判定尺寸和速度随段位提升。所有普通／蓄力远攻继续共用实际发射后 2 秒冷却。练习场出招表和蓄力提示已更新。

守望者两种形态均传递 `damageType: magic`，发射物和释放特效使用绿色能量，不调用原有剑气演出。伤害沿用通用防御、格挡和受击计算。铠甲冲击波在地面施放时贴地移动，并显示短暂裂纹和碎石，不改动场景碰撞地形。贵族的光剑贯穿命中的目标后继续飞行，对同一目标仅伤害一次；格挡或招架仍可截停。

## 素材与生成

四张原始透明动作表均由**内置 image_gen** 根据现有角色图生成，未使用 CLI。完整提示词、参考路径见 [prompts.json](prompts.json)，原始生成输出路径见 [generation-jobs.json](generation-jobs.json)。项目内保留每个角色目录的 `source-sheet.png`。

`tools/build-ranged-arts.cjs` 按 `manifest.json` 中记录的帧索引裁切素材、统一比例并对齐脚底，安装至 `charge/` 和 `release/`。守望者的三段聚能姿势使用原图第三行的竖剑姿势，避免把二段横剑错误用作三段。

运行配置为 `js/ranged-arts-config.js`；实时魔法阵、法球、霜雾、电弧、光剑、冲击波、地裂与粒子由 `js/ranged-arts.js` 绘制。飞行道具类型、蓄力段数、判定大小、形态、魔法伤害类型和方向通过联机快照保留。

## 验证与预览

- `tools/test-ranged-arts.cjs`：三段保持、帧素材、左右命中、段位伤害、发射接触帧、2 秒冷却、7 秒自动释放、守望者形态区分、贵族贯穿去重、联机数据。
- `tools/check-ranged-arts-browser.cjs`：真实浏览器加载全部素材并绘制三段及释放；绿色魔法和金色光剑颜色检查；实际按 U 后松键；练习场招式名；资源与脚本错误检查。
- 既有左轮、连击、特效接触帧、待机、走路、远攻冷却及退出战斗验证通过。
- `gameplay-review.png` 为四行四列完整预览；`release-preview.png` 为四种释放效果的对照图。
