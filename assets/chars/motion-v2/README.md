# Motion and controls revision 2

- Settings now includes **退出战斗，返回主界面** in every mode. It clears battle state, input holds, projectiles and custom objects, closes a connected/in-progress network session, stops media playback and opens the main menu. The existing back button resumes the battle or returns to its previous menu.
- All six fighters and both Shouwang forms use a continuous **60 FPS breathing idle**. This animates the upper body from a stable source pose with a bounded subpixel vertical lift and slight chest expansion, keeping the feet pinned. Paused simulation also freezes the breath. It replaces the previous completely static idle without restoring mismatched ten-frame silhouette jumps. It does not claim sixty newly drawn PNG poses.
- Normal and charged U attacks share a **two-second cooldown measured from actual projectile emission**. Windup also blocks additional casts, so starting another charge cannot bypass the cooldown. Existing 7-second charging caps remain intact. Meter-tier supers remain independent.
- The three new fighters have new complete ten-pose walk cycles at **24 FPS**, with flexed passing legs, alternating support and toe-off. Backward walking reverses those cycles. Run remains 32 FPS. PNGs use a common registration scale, head anchor and planted-foot baseline.

Walk drawings were made with the built-in image_gen tool using the established walk sheet for motion and each new portrait for identity. `prompts.json` and `generation-jobs.json` record the first pass; `corrected-jobs.json` records the final color-corrected sheets (removing light stocking colors accidentally borrowed from the motion reference). Selected final sheets are in `sheets/*-walk-corrected.png`; the manifest records selected cells. Runtime PNGs are in each fighter's walk and walkBack folders. `tools/build-motion-v2.cjs` rebuilds them and `js/motion-v2.js`.

Verification: `tools/test-motion-v2.cjs` checks seven forms' breathing image variation, fixed feet and bounded head displacement; both ranged variants' cooldowns; exiting from thirty mode/phase combinations plus story; settings resume and real-keyboard walking. Network exit is exercised with a stub transport. Existing combat and new-roster mechanics tests also run separately. `tools/test-idle-stability.cjs` now expects smooth motion rather than pixel-identical idle frames.
