# 武器防御姿势

内置 imagegen 根据项目现有立绘生成 `source-atlas.png`。三列两行依次为：贵族细剑架挡、剑客横剑架挡、守望者重铠巨剑壁垒、守望者脱甲掌盾、伊芙琳杖与吸盘触手护身、旅者猎枪护架。第二次生成用脱甲形态原立绘校正身份。

生成提示重点：朝右、完整单一轮廓、保留服饰和武器、稳固站姿、透明背景、无重影。`tools/build-weapon-guards.cjs` 按连通轮廓提取六个角色，排除背景薄雾和邻格武器碎片，统一画布与脚部锚点。运行时持续格挡固定单帧，独立武器属性光效低速变化，避免人物抖动；司夜使用原撑伞防御。伤害减免与破防规则不变。

同时 `js/clean-aerial-config.js` 让剑客、贵族和守望者双形态改用原始独立空中姿势，替换叠帧扩展动作，关闭这些角色在空中的瞬身人物残影。跳跃和二段跳操控逻辑不变。
