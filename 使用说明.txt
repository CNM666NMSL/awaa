百兽夜行 · 贵族 V3 · Windows x64 便携版
打包日期：2026-10-22

一、在另一台电脑上打开
1. 把 ZIP 压缩包复制到另一台 64 位 Windows 电脑。
2. 完整解压到一个普通文件夹，不要直接在压缩软件内运行。
3. 双击“开始游戏.cmd”，浏览器会自动打开游戏主菜单。
   双击“贵族练习场.cmd”，可直接进入贵族动作、招式练习场。
4. 游戏期间保留启动窗口。关闭该窗口或按 Ctrl+C 即可停止游戏。

压缩包已附带 Windows x64 Node.js 运行环境，无需安装 Node.js、npm 或其他依赖。
本机游玩不需要联网。电脑上需要有可用的现代浏览器。
如果浏览器没有自动打开，请复制启动窗口中显示的“游戏地址”到浏览器。
默认端口为 3010；端口被占用时会自动换成可用端口，以窗口显示的地址为准。
不要只复制 index.html；assets、js、runtime 等目录都需要一起保留。

二、游玩
主菜单保留本地双人、在线房间及贵族练习场入口。
贵族练习场提供全部招式按钮、招式参数、对手状态与气量设置。
详细操作以游戏内提示为准，完整动作和数值见 NOBLE-V3.md。
贵族 V3 包含 25 个动画状态、112 张动作帧图及相关特效。

三、同一局域网联机
两台电脑应在浏览器中访问同一个启动窗口显示的“局域网地址”，
然后一方创建房间，另一方输入房间号。请让作为主机的启动窗口保持运行。
如 Windows 防火墙提示访问权限，同一可信网络内联机时允许专用网络访问。

四、继续修改项目
index.html、style.css、practice.css：页面和界面。
js：角色、战斗、动画、练习场与联机逻辑。
assets：完整素材、原始参考图和贵族 V3 动画。
tools：素材制作工具、动作检查与战斗检查脚本。
server.js：本地静态资源与房间联机服务，不依赖第三方 npm 包。
launch-game.cjs：便携启动入口，可使用 --no-open、--port=端口 参数。
runtime：随包附带的 Node.js v24.19.0 Windows x64 运行程序和许可证。

工程源码也已包含在同一压缩包中。
其他操作系统可自行准备 Node.js 18 或以上版本，在工程目录运行
node server.js，然后打开 http://127.0.0.1:3000/ 。
打包使用的运行环境第三方许可与来源见 runtime 目录。
